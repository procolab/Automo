Access the PAN-OS REST API
The PAN-OS REST API URL format includes a base path and the URI for the endpoint.
curl -X GET "https://<IP address or FQDN>/restapi/<PAN-OS version>/<resource URI>"

You can view the full list of resources in the REST API Reference on the firewall or Panorama
at https://<IP_address>/restapi-doc

### Authentication
API Key
curl -X GET \
"https://PA-FW/restapi/v11.0/Policies/SecurityRules" \
-H "X-PAN-KEY: API_KEY"

Palo Alto Security Policy API Operations (Create, Update, Delete, Priority Change)
Palo Alto uses the SecurityRules REST API endpoint for firewall policies. Policies can be managed on:

1. Firewall (VSYS)
2. Panorama Device Group (Pre/Post Rules)

Authentication is typically done using the X-PAN-KEY header.

1. Create Security Policy
### cURL
curl -k -X POST \
"https://PA-FW/restapi/v11.1/Policies/SecurityRules?location=vsys&vsys=vsys1&name=Allow-Web" \
-H "X-PAN-KEY: API_KEY" \
-H "Content-Type: application/json" \
-d '
{
  "entry": [
    {
      "@name": "Allow-Web",
      "description": "Allow Web Traffic",
      "from": {
        "member": ["Trust"]
      },
      "to": {
        "member": ["Untrust"]
      },
      "source": {
        "member": ["10.10.10.0/24"]
      },
      "destination": {
        "member": ["any"]
      },
      "application": {
        "member": ["web-browsing","ssl"]
      },
      "service": {
        "member": ["application-default"]
      },
      "action": "allow"
    }
  ]
}'

### Python
import requests

fw = "10.10.10.1"
api_key = "YOUR_KEY"

url = (
    f"https://{fw}/restapi/v11.1/"
    "Policies/SecurityRules"
    "?location=vsys"
    "&vsys=vsys1"
    "&name=Allow-Web"
)

headers = {
    "X-PAN-KEY": api_key
}

payload = {
    "entry": [{
        "@name": "Allow-Web",
        "action": "allow"
    }]
}

r = requests.post(
    url,
    headers=headers,
    json=payload,
    verify=False
)

print(r.json())

3. Update Security Policy
Modify existing rule attributes.

### cURL
curl -k -X PUT \
"https://PA-FW/restapi/v11.1/Policies/SecurityRules?location=vsys&vsys=vsys1&name=Allow-Web" \
-H "X-PAN-KEY: API_KEY" \
-H "Content-Type: application/json" \
-d '
{
  "entry": [
    {
      "@name": "Allow-Web",
      "description": "Updated through API",
      "action": "allow"
    }
  ]
}'

### Change Action Allow → Deny
{
  "entry": [
    {
      "@name": "Allow-Web",
      "action": "deny"
    }
  ]
}

### Python
requests.put(
    url,
    headers=headers,
    json={
        "entry":[{
            "@name":"Allow-Web",
            "description":"Updated"
        }]
    },
    verify=False
)

6. Change Priority (Move Rule)
Palo Alto policy order is top-down.

### Move Before Another Rule
Move:
Allow-Web
Before
Block-All

curl -k -X POST \
"https://PA-FW/restapi/v11.1/Policies/SecurityRules\
?location=vsys\
&vsys=vsys1\
&name=Allow-Web\
&action=move\
&where=before\
&dst=Block-All" \
-H "X-PAN-KEY: API_KEY"

### Move After Another Rule

curl -k -X POST \
"https://PA-FW/restapi/v11.1/Policies/SecurityRules\
?location=vsys\
&vsys=vsys1\
&name=Allow-Web\
&action=move\
&where=after\
&dst=Allow-DNS" \
-H "X-PAN-KEY: API_KEY"

### Python
move_url = (
    f"https://{fw}/restapi/v11.1/"
    "Policies/SecurityRules"
    "?location=vsys"
    "&vsys=vsys1"
    "&name=Allow-Web"
    "&action=move"
    "&where=before"
    "&dst=Block-All"
)

requests.post(
    move_url,
    headers=headers,
    verify=False
)
